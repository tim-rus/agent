# Журнал разработки

Делаю демонстрационного ии-агента.

*GMT +5*

## Задача

Основная идея - сделать ии-агента-переговорщика, который будет "продавать" меня работодателю и отстаивать мои интересы. Сделать его омниканальным (telegram bot, web).

Дополнительно - хочу добавить этому агенту характер, эмоциональный образ. Пока в голове сидит агент по продажам подержанных авто из Трансформеров (Uncle Bobby B, baby!), но по ходу будет видно. 

Еще неплохо было бы добавить панель с информацией о текущем состоянии диалога и возможностью менять настройки диалога. Плюс добавить дашборд со статистикой. И то и то real time.      

Бонус (если успею) - красивые сопроводительные письма для каждого работодателя. С редактором.

Все это дает простор для демонстрации навыков: тут и ии-специфика (контекст, промпты, векторизация/rag итд) и тех-навыки (бэкенд/фронтенд, межсервисное взаимодействие, интеграции итд).

## Стек

Поскольку проект демонстрационный, стек будет разнообразным:
- **go**: api, бизнес-логика, взаимодействие с llm
- **python**: взаимодействие с telegram bot api
- **type script**: пользовательский интерфейс (**react**) и админка (**vue**)
- **surrealdb**: основная база приложения; **document/graph/vector**
- **sqlite**: вспомогательная база для телеграм бота; **relational**
- **clickhouse**: телеметрия; **column/timeseries**
- **connect rpc**: связь между компонентами системы
- **docker/compose**: работа с контейнерами

## Процесс

Всю задачу хотелось бы уложить в 3 дня, поэтому делаю быстро, итерациями.  

В основном буду писать руками (все-таки демонстрационный проект), но что-то буду вайбить - тоже навык.  

Процесс буду журналировать, чтобы можно было отследить не только код, но и ход моих мыслей.
