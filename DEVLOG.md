# Журнал разработки

Делаю демонстрационного ии-агента.  

## Задумка

Когда я думал, какого агента делать, у меня в голове крутились два образа: Джерри Магуайер и Дядя Бобби Би - продавец подержанных авто из Трансформеров.  

Решил сделать комбинацию: **персональный агент, который будет "впаривать" меня работодателю**.  

С одной стороны - эмоция. Карикатурный персонаж запомнится и сделает демо не таким скучным.

С другой - это дает простор для демонстрации практических навыков. 

<br>

Технически все это будет 4-мя сервисами:
* core (**go**) - ядро, бизнес-логика, взаимодействие с llm
* tg (**python**) - взаимодействие с telegram bot api
* ui (**react**) - пользовательский интерфейс
* admin (**vue**) - админка

<br>

Для хранения данных буду использовать:
* **surrealdb** (nosql/vector/graph) - основная база
* **sqlite** (sql) - вспомогательная база для telegram-бота
* **clickhouse** (column/timeseries) - телеметрия

<br>

Для связи буду использовать **ConnectRPC** (удобно)  
Деплоить буду на vds (Debian 13) с **docker/compose**  
Для команд буду использовать **Taskfile**  

<br>

Весь **процесс буду журналировать**, что позволит отследить ход моих мыслей.

На все выделяю себе **3 дня**.
